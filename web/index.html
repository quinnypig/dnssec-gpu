The experiment followed this DNSSEC discussion and Thomas H. Ptáček’s response. It does not settle the disagreement.

Benchmark code, not a production signer. The GPU implementation uses variable-time CGBN arithmetic without RSA blinding. OpenSSL’s CPU path includes protections this prototype does not. This is not a comparison of equally hardened implementations.

Signatures are generated ahead of queries. This does not make ordinary DNS lookups faster, and it says nothing about ECDSA or Ed25519 performance.
