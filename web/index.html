Now with a CUDA dependency.

Prompted by this DNSSEC discussion and Thomas H. Ptáček’s reply. It settles nothing.

Benchmark code. Don’t sign anything real with it. The GPU path uses variable-time CGBN arithmetic and no RSA blinding. OpenSSL’s CPU path has protections this prototype lacks, so these are not equally hardened signers.

Zones are signed before anyone queries them. This won’t make a single DNS lookup faster, and it says nothing about ECDSA or Ed25519.

Bring your own GPU.

The script builds a test zone, signs it both ways, compares the output byte for byte and runs BIND’s verifier.
